Pesquisa de Filmes com IA

01. Introdução

Gastamos mais tempo navegando nos menus do que assistindo aos filmes;

Para resolver isso, desenvolvemos uma aplicação que utiliza inteligência artificial e dados para mapear conexões de filmes;

02. Metodologias Utilizadas

  • Linguagem & Framework: Backend desenvolvido em Python com Flask, garantindo uma API leve e veloz;
  • Inteligência de Dados: Uso da biblioteca Pandas para manipulação e cruzamento de datasets complexos;
  • Frontend Moderno: Interface responsiva em HTML5 e CSS3, focada em UX (Experiência do Usuário);
  • Inteligência Artificial: Algoritmos baseado em KNN para análise e recomendação de filmes.

03. Conclusão

Integração Técnica: O projeto demonstra a viabilidade de unir ferramentas de Data Science (Pandas) com desenvolvimento Web (Flask/JS).

Eficiência de Dados: A lógica de "filtros invertidos" provou ser uma alternativa superior aos sistemas de busca tradicionais.

Potencial de Escalabilidade: A arquitetura modular permite integrar novos algoritmos de Machine Learning com facilidade.
